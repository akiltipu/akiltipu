## About me

I build secure, scalable, observable, and cost-efficient cloud platforms on AWS. My work spans infrastructure architecture, Infrastructure as Code, container orchestration, CI/CD, serverless systems, cloud security, observability, automation, and production operations.

I enjoy taking ownership beyond deployment: investigating complex failures, improving engineering workflows, reducing operational overhead, mentoring teammates, and turning recurring manual work into reliable automation.
